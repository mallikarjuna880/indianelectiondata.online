# Frontend

Next.js/React application target for the public election platform.

Planned routes:
- `/`
- `/elections`
- `/elections/[id]`
- `/constituencies/[id]`
- `/candidates/[id]`
- `/parties/[id]`
- `/states/[id]`
- `/analysis`
- `/admin`

The existing static GitHub Pages frontend is intentionally preserved while the platform backend is built and tested.
