ABOUT THE PROJECT

A simple public-data platform for Indian elections.

This first version is a static GitHub Pages website. It is designed so election datasets can be added later without rebuilding the entire interface.

Next: official datasets, constituency pages, candidate profiles, historical comparisons, charts, map visualisation, SEO pages and a data-download section.
