# Indian Election Data — Version 1

Static, responsive prototype for `indianelectiondata.online`.

## Files
- `index.html` — page structure
- `styles.css` — responsive design
- `data.js` — demo election data
- `app.js` — search and rendering logic

## Publish on GitHub Pages

1. Create/open the repository.
2. Upload these four files (and this README).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. After deployment, GitHub will provide a Pages URL.

## Custom domain

Add `indianelectiondata.online` in the Pages **Custom domain** setting, then create the DNS records requested by GitHub at your domain registrar.

## Important data note

`data.js` contains **prototype/demo records** for the interface. Do not present those records as an authoritative election database. Replace them with verified data before launch, preferably from the Election Commission of India and other authoritative public sources.
